# KAD ELEVATE Academy 2.0

أكاديمية تطوير ثنائية اللغة تحول مفاهيم القيادة والتواصل وحل المشكلات والتسليم والتكيف إلى ممارسة موثقة داخل العمل.

## الإصدار 2.0

| المجال | التسليم |
|---|---|
| المسارات | 5 مسارات فعالة: LEAD, CONNECT, SOLVE, DELIVER, ADAPT |
| الوحدات | 30 وحدة أصلية بالعربية والإنجليزية |
| التقييم | 150 سؤالًا تدريبيًا مع تفسير الإجابات |
| التطبيق | موقف كاد، خطأ شائع، مهمة ودليل تطبيق لكل وحدة |
| المستويات | L1–L5 من قيادة الذات إلى مسؤولية المؤسسة |
| Personal Mode | يعمل محليًا دون تسجيل ويحفظ البيانات في المتصفح |
| Team Mode | Node.js + SQLite بحسابات وصلاحيات وتصحيح خادمي ومراجعات |
| المحتوى المحفوظ | مكتبة الإصدار السابق: 20 درس فيديو و119 سؤالًا و9 حالات و9 أدوات |

إكمال وحدة ELEVATE يتطلب إقرار القراءة، ودرجة 80% أو أكثر، وتطبيقًا مكتوبًا لا يقل عن 80 حرفًا. هذه أدلة تعلم تكوينية وليست اعتمادًا مهنيًا أو قرارًا آليًا للموارد البشرية.

## التشغيل

Personal Mode، دون تثبيت حزم:

```bash
npm run dev
```

ثم افتح `http://127.0.0.1:4173`.

Team Mode:

```bash
npm run build
npm run team:bootstrap -- --email admin@company.example --name "KAD Administrator"
npm run team
```

ثم افتح `http://127.0.0.1:3000/#/login`. التفاصيل الأمنية والتشغيلية في [backend/README.md](backend/README.md).

## أوامر الجودة

```bash
npm run check
npm test
npm run build
```

## بنية المشروع

- `src/data/academy.mjs`: المسارات الخمسة والوحدات الثلاثون والأسئلة المئة والخمسون.
- `src/app.mjs`: تجربة ELEVATE، التعلم الشخصي وواجهة الفريق.
- `src/core`: قواعد الإكمال والتخزين والتحقق والاستعادة.
- `backend`: خدمة الفريق، SQLite، الهوية والجلسات والصلاحيات.
- `content`: صادرات المحتوى المنفصلة عن العرض.
- `docs`: الهندسة والمصادر والتشغيل والخصوصية والجودة.
- `dist`: Personal Mode ثابت وجاهز للنشر.

## حدود النشر

نشر Vercel يعرض Personal Mode الثابت. Team Mode يحتاج خدمة Node واحدة وقرصًا دائمًا لـSQLite وHTTPS ونسخًا احتياطية مشفرة واختبار استعادة. لا تنشر قاعدة البيانات على تخزين serverless مؤقت.

المراجع الخارجية للاستزادة ولا تعني شراكة أو اعتمادًا أو ترخيص إعادة استخدام مؤسسي. المحتوى الأساسي داخل الوحدات مؤلف خصيصًا لـKAD ELEVATE ولا يعتمد على بقاء رابط خارجي متاحًا.
