# KAD Growth Academy
## KAD Soft Skills Program · Open Edition 1.0.1

نسخة تشغيلية ثنائية اللغة لمسار أساسيات القيادة، مصممة بهوية Kader & Associates Designs.
لا تحتاج إلى تسجيل دخول أو مفاتيح API. التقدم والملاحظات والتطبيقات محفوظة على متصفح المستخدم نفسه، وليس على قاعدة بيانات موظفين مركزية.

---

## 🎨 الهوية البصرية الجديدة

تم تحسين النظام البصري بالكامل لتمثل هوية KAD Designs الاحترافية:

### ألوان محسّنة
- ✅ نظام ألوان موحد بـ CSS Variables
- ✅ تحسين تباين الألوان للـ WCAG 2.2 AA
- ✅ ألوان أنظف وأكثر احترافية

### Typography محسّن
- ✅ خط **Inter** للإنجليزية
- ✅ خط **Cairo** للعربية (خط عربي احترافي)
- ✅ حجم الخط أساسي **16px** للقراءة المريحة
- ✅ نطاق Typography موحد (1.25 ratio)

### Layout محسّن
- ✅ تخطيط متجاوب محسّن للشاشات المختلفة
- ✅ دعم كامل للـ RTL واللغة العربية
- ✅ تحسينات في الوصائل والمسافات

**ابدأ من هنا:** على Windows، فك الضغط ثم شغّل `START-WINDOWS.cmd` بعد تثبيت Node.js 20 أو أحدث.
أو افتح مجلد المشروع في VS Code ونفّذ:

```bash
npm run dev
```

ثم افتح:

```text
http://localhost:4173
```

لا توجد حزم تحتاج إلى `npm install`. لا تستخدم أمر التثبيت لتشغيل هذه النسخة.

### المعاينة السريعة

افتح `dist/index.html` لعرض الموقع دون خادم. الواجهة والكويزات والأدوات مضمّنة في الملف.
للمشاهدة داخل مشغل YouTube استخدم الخادم المحلي أعلاه أو استضافة HTTPS؛ داخل ملف `file://` يعرض الموقع رابط الفيديو الأصلي كبديل. يلزم الاتصال بالإنترنت لمشاهدة الفيديوهات.

## تجربة التعلم

`Assess → Learn → Check → Apply → Reflect`

داخل كل درس: رابط ومشغل المصدر، موجز تعليمي أصلي، أهداف، اختبار مصحح مع تفسير الإجابات،
ملاحظات، تأمل تطبيقي، وحفظ الدرس.

اكتمال الدرس يتطلب:
- تغطية 90% من الثواني المقاسة عبر المشغل الرسمي (التبويب المخفي لا يُحتسب، وتخطي المقاطع لا يُحتسب).
- فتح الاختبار بعد التغطية فقط؛ أفضل نتيجة لا تقل عن 80%.
- تأمل تطبيقي لا يقل عن 40 حرفًا.
- لا يوجد زر مشاهدة يدوي: التأكيد الذاتي الخارجي لم يعد يُحتسب.

## رحلتا اللغة والتخزين

- أول تشغيل يعرض بوابة اختيار اللغة؛ العربية رحلة عربية كاملة والإنجليزية رحلة إنجليزية كاملة، دون استبدال تلقائي. تغيير اللغة لاحقًا لا يحذف التقدم.
- التخزين الأساسي IndexedDB (`kad_growth_v2`) مع مرآة `localStorage` وطلب ثبات التخزين حيثما أمكن؛ لوحة صحة التخزين في الإعدادات. التفاصيل: `docs/DATA_PERSISTENCE.md` والترحيل: `docs/MIGRATION_V1_V2.md` وسياسة الفيديو: `docs/VIDEO_POLICY.md`.

المشاهدة الذاتية واضحة وليست إثبات حضور مراقَبًا. درجات الاختبارات تقيس الفهم في هذه الأنشطة،
ولا تُحوَّل إلى ادعاء قياس موضوعي للكفاءة القيادية. لا يوجد ترتيب علني للموظفين.

سجل الإكمال النهائي مشروط بإكمال 20 درسًا و9 تطبيقات وتسليم التحدي الختامي.
هو **سجل تعلم شخصي** قابل للطباعة، وليس شهادة اعتماد أو إقرارًا بمراجعة مدير.

## الصفحات

- الرئيسية، المسار، الدروس، مكتبة البحث والفلاتر، الدروس المحفوظة.
- التطبيقات، أدوات العمل، الملاحظات، التقييم القبلي والبعدي، التقدم، التحدي النهائي، الإنجازات.
- الملف المحلي، الإعدادات، تصدير واستيراد نسخة احتياطية، الدعم، حول البرنامج، المصادر، الخصوصية والشروط.
- تسجيل الدخول وإنشاء الحساب واسترجاع وإعادة تعيين كلمة المرور: واجهات مستقبلية معطّلة.
- معاينة المدير، الإدارة، سجل المحتوى، بنك الأسئلة، مخططات المراحل المستقبلية، تقارير الدعم المحلية.

المعاينات الإدارية متاحة من رابط `Admin preview` أسفل الموقع، أو من `#/admin`.
لا تضع بها بيانات موظفين حقيقية؛ لا توجد مصادقة أو صلاحيات مركزية في هذه النسخة.

## أوامر المشروع

```bash
npm run dev        # تشغيل المصدر
npm run check      # فحص سلامة المحتوى والمعرّفات
npm test           # اختبارات المنطق
npm run build      # إنتاج dist/index.html
npm start          # تشغيل نسخة dist
npm run export     # تصدير المحتوى إلى JSON
```

لاستخدام منفذ آخر:

```bash
npm run dev -- --port 8080
```

تحتاج اختبارات المتصفح فقط إلى Python + Playwright + Chromium. ليست هذه متطلبات تشغيل الموقع.

## البيانات والخصوصية

مفتاح التخزين: `kad-growth.open.v1`.
البيانات مرتبطة بالمتصفح وملف المستخدم وأصل الموقع. تغيير المنفذ أو الدومين لا ينقلها تلقائيًا.
صدّر نسخة JSON من الإعدادات قبل تغيير الجهاز أو حذف بيانات المتصفح، ثم استوردها على الجهاز الجديد.
الاستيراد يستبدل السجل الحالي بعد تأكيدك، ولا يدمجه.

لا يوجد تتبع تحليلي خارجي أو طلب تسجيل بريد. عند تحميل المشغل يتصل المتصفح بيوتيوب؛ هذا الاتصال
ليس جزءًا من التخزين المحلي. لا تكتب أسماء عملاء أو تفاصيل مشاريع سرية داخل التأملات أو بلاغات الدعم.

## حدود النسخة الحالية

1. لا يوجد Backend متصل أو مزامنة متعددة الأجهزة أو قاعدة بيانات موظفين.
2. صفحة المدير لا تعرض فريقًا وهميًا؛ المقاييس المركزية غير متاحة.
3. تعديلات الإدارة تغيّر سجل هذا المتصفح فقط. تعديل المصدر وإعادة البناء هو طريق النشر للجميع.
4. الأسئلة مكتوبة خصيصًا للمنصة ومرتبطة بموضوع الدرس وموجزه الأصلي، وليست اختبارات ناشري الفيديوهات.
5. تمت مراجعة تطابق عناوين وروابط المصادر في البحث العام؛ لم يُختبر التشغيل الحي لكل فيديو من بيئة البناء.
6. المدة الدقيقة ومسارات الترجمة والتوافق الكامل مع النص المنطوق لم تُعتمد مسبقًا. لا تُختلق هذه البيانات.
7. الإتاحة على YouTube لا تعني ترخيصًا مؤسسيًا عامًا. يلزم إغلاق مراجعة الاستخدام قبل تعميم برنامج إلزامي.
8. أُعدت ملفات النشر، لكن لم يُنشأ رابط عام في جلسة البناء. لا توجد أسرار أو مفاتيح حسابات في الحزمة.

تفاصيل التنفيذ والاختبارات وخطوة الترقية المؤسسية موجودة في ملفات `docs/` و`backend/`.
