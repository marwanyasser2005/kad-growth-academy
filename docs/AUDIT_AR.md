# تدقيق وتنفيذ KAD ELEVATE 2.0

تاريخ التنفيذ: 17 سبتمبر 2026.

## الفجوات التي عالجها الإصدار

- أصبح مقام التقدم 30 وحدة مشتركة بين العربية والإنجليزية بدل جمع فيديوهات رحلتين مختلفتين.
- صار المحتوى الأساسي نصًا أصليًا مستقلًا عن تشغيل الفيديو؛ المكتبة المرئية مورد إضافي محفوظ.
- أضيفت خمسة مسارات فعالة و150 سؤالًا تدريبيًا وتصميم مستويات L1–L5.
- أضيف مسار إكمال واضح: قراءة + 80% معرفة + 80 حرفًا من التطبيق الموثق.
- توسع التخزين المحلي ليشمل تقدم وحدات ELEVATE مع التحقق من بنية النسخ المستوردة.
- أضيف Team Mode حقيقي بخادم Node وSQLite وجلسات وصلاحيات وتصحيح اختبارات على الخادم وأدلة مشتركة عمدًا ومراجعات وسجل تدقيق.
- أعيد بناء الواجهة حول هوية KAD بالأبيض والأسود والأحمر، مع RTL/LTR وتجاوب الهاتف وتقليل الحركة والوضع الداكن.

## ما بقي من الإصدار السابق

حُفظت 20 درس فيديو و119 سؤالًا و9 حالات و9 أدوات داخل مكتبة المصادر والتطبيق. لم تُحذف معرفة سابقة لمجرد إعادة تصميم الصفحة الرئيسية.

## حدود صريحة

- Personal Mode سجل ذاتي قابل للتعديل عبر المتصفح.
- Team Mode يحتاج قرصًا دائمًا وHTTPS واعتماد سياسة احتفاظ وحذف قبل بيانات الموظفين.
- لا يوجد SSO أو MFA أو بريد آلي أو HRIS أو SCORM/xAPI أو شهادة اعتماد.
- لا تعني درجات الاختبار كفاءة متحققًا منها أو توصية ترقية.
- لم يُنفذ اختبار اختراق أو حمل إنتاجي أو اعتماد WCAG خارجي.

## أدلة القبول

- `npm run check`: يتحقق من 5 مسارات و30 وحدة و150 سؤالًا، إضافة إلى المحتوى المحفوظ.
- `npm test`: يختبر قواعد الإكمال والتخزين والهجرة والمحتوى.
- `npm run build`: ينتج `dist/index.html` مستقلًا للوضع الشخصي.
- فحص المتصفح يغطي الصفحة الرئيسية والوحدة وإكمال الاختبار وRTL وعرض الهاتف وعدم التزاحم الأفقي.
