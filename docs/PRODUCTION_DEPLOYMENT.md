# دليل نشر KAD ELEVATE Academy 2.0

## التحقق قبل الإصدار

```bash
npm run check
npm test
npm run build
```

النتيجة المعتمدة للإصدار 2.0: خمسة مسارات، 30 وحدة، 150 سؤالًا جديدًا، 41 اختبارًا ناجحًا، مع الحفاظ على مكتبة الإصدار السابق.

## Personal Mode على Vercel

المشروع مرتبط بـ Vercel ويستخدم `vercel.json` لنشر مجلد `dist/`:

```bash
npx vercel deploy --prod --yes
```

يجب التحقق بعد النشر من صفحة البداية، تبديل العربية والإنجليزية، فتح وحدة، وإتمام مسار القراءة والاختبار ودليل التطبيق. تفرض الاستجابة CSP و`nosniff` وسياسة إحالة وصلاحيات متصفح مقيدة.

## Team Mode

Team Mode خدمة Node/SQLite ذات حالة دائمة، ولذلك تُنشر على بيئة Node توفر قرصًا دائمًا:

```bash
Copy-Item .env.example .env
npm run team:bootstrap
npm run team:start
```

اضبط `KAD_ORIGIN` على الأصل العام الصحيح، واحفظ `backend/data/` على قرص دائم، واحتفظ بكلمة المرور المؤقتة خارج السجلات. يجب أن يعمل التطبيق خلف HTTPS، مع وكيل يعيد توجيه الطلبات إلى منفذ الخدمة.

## فحص التشغيل

- `GET /api/health` يعيد الإصدار 2.0.
- تسجيل الدخول ينشئ جلسة Cookie آمنة ويعيد رمز CSRF.
- الأسئلة العامة لا تكشف `correctId`.
- التصحيح والحفظ يتمان على الخادم عند استخدام Team Mode.
- حساب المدير يستطيع عرض الفريق ومراجعة الأدلة، بينما المتعلم لا يصل إلى مسارات الإدارة.

## حدود النشر

نسخة Vercel الثابتة تشغّل Personal Mode بالكامل. تشغيل Team Mode على Vercel Serverless من دون قاعدة بيانات أو قرص دائم سيؤدي إلى فقدان الحالة، لذلك لا يُعتمد بهذه الصورة.
