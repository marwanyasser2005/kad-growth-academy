## Source-specific versus original material

The Arabic and English course titles can be edited teaching labels rather than exact publisher headlines. The official watch link identifies the underlying resource. No transcript or source video is redistributed.
Every lesson carries a bilingual original practice brief that supports its original quiz. Do not describe these questions as authored, graded, or endorsed by Edraak, HBR, Stanford, or Simon Sinek.

## Metadata status

`durationSeconds: null` means the exact duration has not been pre-verified; it is read from the actual player when available.
`captions: unknown` means captions have not been verified. Bilingual platform text does not promise translated video audio.
`reuse: review_required` prevents an unsupported enterprise-licensing claim. Technical embedding availability is not sufficient proof.

Use `npm run verify:sources` for an optional metadata-resolution check. Review its limitations before acting on the result.
